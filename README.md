# MVJ Data Analytics Internship 2026–27

## About
This repository contains the work completed during the BCA (Data Science) final-year internship at MVJ Degree College, following the Data Analytics track.

## Objectives
- Learn data analytics concepts and techniques.
- Practise working with datasets using Excel, SQL, and Python.
- Create reports and dashboards using Power BI.
- Maintain a record of daily internship activities and learning.
