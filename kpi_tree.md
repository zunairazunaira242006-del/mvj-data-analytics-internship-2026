Namma Metro KPI Tree

## Main Goal

Understand and improve Namma Metro's performance using data.

## 1. Ridership

* Daily passenger count
* Passengers per train
* Passenger count by station

## 2. Peak-Hour Share

* Peak-hour passenger count
* Total daily passenger count
* Peak-hour share (%) = (Peak-hour passengers / Total daily passengers) × 100

## 3. Revenue Proxies

* Estimated fare revenue
* Average fare per trip
* Number of paid trips

## Questions for Analysis

* How does daily ridership change over time?
* Which hours have the highest passenger demand?
* Which stations have the highest passenger counts?
* How do ridership and estimated fare revenue change together?
